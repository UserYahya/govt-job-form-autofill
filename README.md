# BD Govt Job Application Form Autofill Script

This JavaScript snippet automates the filling of any Bangladeshi govt job application (Example: [Jiban Bima Corporation (JBC)](http://jbc.teletalk.com.bd) ) form. It is designed to save time when applying to multiple positions by pre-populating form fields using the browser console.

## 🚀 How to Use

1. Open the JBC application page. For example:  
   [http://jbc.teletalk.com.bd/application.php](http://jbc.teletalk.com.bd/application.php)

2. Press `F12` to open Developer Tools → go to the **Console** tab.

3. Paste the contents of `autofill.js` and hit **Enter**.

4. The form will be filled automatically.

5. Upload your **photo and signature** manually and review the information before submission.

---

## 🛠 Features

- Fills out personal information
- Handles dynamic fields (NID, BReg, Passport)
- Automatically sets district and upazila (e.g., "Patharghata")
- Alerts when finished
